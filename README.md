# へきが ドットえメーカー

Chrome / Chromebook 用の静的Webアプリ。アカウント、外部サービス、追加パッケージは不要です。

## ローカル起動

```sh
cd /workspace/shikikatsu
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `/index.html` を開きます。作品はメモリー上に保持し、ページを閉じると消えます。閉じる前にJPEGで保存してください。

## 公開（GitHub Pages）

1. このフォルダーの `index.html`、`index2.html`、`app.js`、`style.css` を GitHub リポジトリの `main` ブランチのルートにコミットしてプッシュします。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。
3. Branch を **main**、フォルダーを **/ (root)** にして Save します。
4. デプロイ完了後、Pages画面に表示されるURLを共有します。通常は `https://shikikatsu.github.io/shikikatsu/` です（未公開のため、このURLでの動作は未検証）。
5. ログアウト状態またはシークレットウィンドウで開けることを確認してから児童に共有します。

公開ページは児童のアカウント不要です。GitHubの組織ポリシーや契約でPages公開が制限される場合は、管理者に公開サイトの利用許可を確認してください。無料の個人プランでは通常、公開リポジトリを使用します。児童の作品はサーバーへ送信されません。

## 操作と印刷

クリックで1マス、ドラッグで長方形。けしゴム、もどる、すすむに対応。キーボードでもキャンバスにTabで移動し、矢印とSpace/Enterで操作できます。

JPEGは3000×1000px、白背景、外枠付き。方眼線の有無を選べます。

印刷にはアプリの「B4でいんさつ」を使用し、日本のB4・横向き・倍率100％・ヘッダー/フッターなしを指定します。下絵は300×100mm、1マス10mmです。プリンタードライバーが縮小する可能性があるため、印刷後に定規で寸法を確認してください。
